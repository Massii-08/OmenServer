## 🧩 Extension Chrome « Coach TradingView » (2026-09-09, v0.1)

Le coach du module Trading, dans l'onglet TradingView de Massii. Spec `docs/superpowers/specs/2026-09-09-tv-coach-extension-design.md`, plan `docs/superpowers/plans/2026-09-09-tv-coach-extension.md`, README d'installation `tools/tv-coach-extension/README.md`.

- **Extension** (`tools/tv-coach-extension/`, Manifest V3, vanilla JS, 0 build, 0 dépendance, chargée « non empaquetée ») : `bridge.js` en `world: "MAIN"` lit `window.TradingViewApi` (symbole, intervalle, bid/ask, dessin) et parle à `content.js` par `postMessage` + nonce + origine ; `content.js` = panneau shadow-DOM `#omen-coach` (fiche, ticket, garde-fous, ledger de scalps, dessin) ; `sw.js` = token + appels API (`host_permissions` omenserver.org et localhost:8000) + WS `/ws/paper` + WS Binance en mode scalp BTC ; `content-omen.js` = bouton « Connecter l'extension coach » sur omenserver.org (copie `localStorage.omenserver_token`, jamais de mot de passe). Modules purs testés `node --test "tools/tv-coach-extension/tests/*.test.js"` (110 tests).
- **Backend** (`backend/bots/paper/`) : `brief.py` (fiche `GET /api/paper/brief`, table symboles TradingView→Yahoo miroir de `lib/symbols.js`), `precheck.py` (`POST /precheck`, 0 LLM, 0 réseau), `fees.py` (+ profils `tv_paper`, `kraken_spot`, `kraken_futures`, `custom`), `tvnews.py` (flux public `news-mediator.tradingview.com`, 60 s/titre, corps via `news-headlines`), `tvcalendar.py` (calendrier éco TradingView → agenda `macro`), `focus.py` (titre affiché, TTL 10 min), `scalps.py` (ledger `<user>.scalps.json`, recalcul serveur, biais, bilan LLM plafonné 3/j), `btc.py` (funding/OI Binance, DVOL/index Deribit, Fear & Greed, prime Coinbase, gap CME via Yahoo `BTC=F`, agenda crypto calculé, facteurs `funding_extreme`/`oi_buildup` jamais dans `THREAT_FACTORS`). Routeur `backend/bots/paper_tv_router.py` (préfixe `/api/paper`, sections par lot), WS `backend/bots/paper_ws.py` (auth PAR PREMIER MESSAGE, 1008 sinon, `emit` best-effort depuis `convergence.maybe_fire`).
- **Mode scalp** (intervalle 1-5 min) : fills DANS l'extension sur le prix live, garde-fous purs `lib/guards.js` (spec §6.3), `POST /scalps` recalcule tout (refus ±5 % de la cotation serveur). Le coach n'est jamais dans la boucle d'un scalp : bilan de session seulement.

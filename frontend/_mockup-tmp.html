🎨 Ce qui définit Bento Tech pour OmenServer :
• Cards border-radius: 14px avec hairline border #27272A · pas d'ombre · pas de gradient (sauf sparkline subtil)
• Grille bento 2fr 1fr 1fr 1fr × 2 rows — la stat principale (CPU) est 2× plus grosse que les autres
• Inter pour le texte UI · Geist Mono + font-feature-settings:"tnum" pour TOUS les chiffres
• Surface 3 niveaux : --bg #0E0E10 · --bg-elev-1 #161618 · --bg-elev-2 #18181B — différentiation subtile sans flashy
• Accent variable via data-accent sur <html> — l'app entière réagit
• Status badges en pill (online/offline/running/warn) — pas de texte hardcodé, juste forme + couleur

🚫 Ce qui est volontairement absent (anti IA-slop) :
• Aucun dégradé violet/bleu de fond · aucun glassmorphism · aucune ombre floue · aucune icône emoji UI
• Pas de "modern card with subtle shadow" · pas de border-radius incohérent

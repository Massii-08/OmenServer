### Frontière clone-hybride (documentée, brief §5)
Les visées **INTERNES des plugins** restent gérées par eux : `pvp.attack` re-track la cible chaque tick, `collectBlock` vise le bloc pour le dig, `pathfinder` oriente la marche → un swing AVANT serait écrasé au tick suivant. Les humaniser exige de **découpler le contrôle de la visée** de ces plugins (réécriture du look pendant combat/dig/marche) — c'est la frontière clone-hybride restante. L'anti-snap actuel couvre les look-ats **délibérés que notre code contrôle** (demi-tours, faire face à un joueur) + la motricité **idle** (D) + le **délai de réaction** (C, déjà anti aimbot-0ms).
